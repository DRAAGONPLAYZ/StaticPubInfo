This Privacy Policy explains what information Static collects, why it is collected, how it is used and stored, who may access it, how long it is retained, and how you can request deletion.

Static is a Discord bot operated by Static Dev Team.

1. Data Collected

Depending on the features you use, Static may store the following information associated with your Discord account:

General Bot Usage

  • Discord User ID
  • Discord Server (Guild) ID
  • Command usage information
  • Last command used
  • Last usage time

AI Features

When using Static's AI features, Static may additionally store:

  • The most recent prompt sent
  • AI usage count
  • A short AI-generated profile based on previous AI interactions

The AI-generated profile may describe non-sensitive usage patterns such as preferred response styles, common topics, or similar information needed to improve Static's responses.

Leveling System

When using Static's leveling features, Static may store:

  • Discord User ID
  • Discord Server (Guild) ID
  • Current XP
  • Current level
  • Leveling-related statistics, such as progress toward the next level

Leveling data is used to maintain your progression within each Discord server. Progression may be separate between servers.

Information Static Does Not Intentionally Collect

Static does not intentionally collect or store:

  • Passwords
  • Email addresses
  • IP addresses
  • Payment information
  • Sensitive personal information
  • Private Discord messages unrelated to features that require them

Static does not knowingly collect data from users under 13.

Users should avoid submitting sensitive or confidential information through AI prompts or other bot features. Information submitted to features that store user input may be retained according to this policy.

2. Why Data Is Collected

Static uses collected information to:

  • Provide and maintain bot features
  • Maintain user leveling and XP progression
  • Improve AI responses and personalization
  • Track command usage and feature activity
  • Provide relevant moderation or administrative context
  • Provide authorized staff-only information commands
  • Detect, troubleshoot, and prevent misuse of the bot
  • Maintain the reliability and functionality of Static

Static only collects information that is reasonably necessary for these purposes.

3. Leveling Opt-Out

Static provides a specific option for users to opt out of the leveling system.

Users who opt out will not have leveling progression maintained for them while the opt-out is active.

Because leveling data is required for certain leveling-related features, opting out may restrict or disable access to some Static features that depend on the leveling system.

Opting out of leveling does not necessarily delete other information Static may have collected for unrelated features, such as AI functionality. Those types of data are handled separately under this policy.

If a user later opts back into leveling, Static may begin collecting and storing the information necessary to provide leveling features again.

4. Server-Specific Data

Some information is associated with both your Discord User ID and a Discord Server ID.

This allows Static to provide features that are specific to individual servers, such as server-specific leveling progression.

Leaving a server does not necessarily cause associated data to be deleted immediately. You may request deletion as described in Section 7.

5. Third-Party Services

Static relies on third-party services to operate certain features and its infrastructure. These services may process information as necessary to provide their respective services.

Groq

Static may use Groq to process requests submitted through Static's AI features.

When an AI feature is used, information necessary to process the request may be transmitted to Groq. Static's own data practices and Groq's handling of information are separate.

Groq states that, by default, customer data for inference requests is not retained, although customer data may be retained in limited circumstances, such as when required by a feature or when necessary to protect platform reliability or investigate abuse. Groq also retains usage metadata for its services.

For more information, review Groq's Privacy Policy.

WispByte

Static is hosted using WispByte infrastructure.

Because Static runs on third-party hosting infrastructure, information necessary for the operation, security, and reliability of the hosting service may be processed by WispByte or its infrastructure providers.

Static does not control WispByte's independent data practices. Users should review WispByte's applicable privacy policies and terms for information about how WispByte handles information relating to its hosting services.

Discord

Static operates through the Discord platform. Discord independently processes information associated with Discord accounts, servers, messages, and use of its platform.

Static does not control Discord's data practices. Discord's own privacy policy and terms apply to information processed directly by Discord.

Static only accesses Discord information through the permissions and intents required for its features.

6. Data Retention

Data is generally retained until:

  • You request deletion,
  • The data is no longer reasonably necessary for the feature that uses it,
  • A major bot update or data reset removes existing records, or
  • Static is discontinued.

Retention periods may vary depending on the type of data and the technical requirements of the feature.

Deleting your data may prevent Static from restoring previous AI personalization, XP, levels, or other stored progress.

7. Data Access

Stored user data may be accessed by:

  • The bot owner
  • Designated co-owners
  • Authorized Static Dev Team staff when reasonably necessary to operate, maintain, troubleshoot, or moderate Static

Access is limited to authorized individuals and should only be used for legitimate administrative or operational purposes.

Static does not sell, rent, or intentionally distribute user data to third parties.

Third-party service providers may process information as necessary to provide services used by Static, as described in Section 5.

8. Data Deletion

You may request deletion of your stored Static data at any time.

If available, you may use:

/info delete
or open a support ticket.

Deletion through /info delete is processed automatically as quickly as Static can respond. Ticket-based requests may take longer.

A deletion request may remove data associated with your Discord User ID, including applicable AI information and leveling progression.

Some technical logs or information required for security, abuse prevention, or legal or operational purposes may not be immediately removable.

AI Data After Deletion

Deleting your AI-related data does not permanently prevent Static from collecting AI-related data in the future.

If you use Static's AI features again after deleting your AI data, Static may once again collect and store the information described in the AI Features section of this policy.

If you want to prevent further AI-related data collection, do not use features that require that information to be collected.

Leveling Data After Deletion

Deleting your leveling data may remove your stored XP, level, and related progression.

If you continue using or re-enable Static's leveling features afterward, new leveling data may be collected and stored again.

9. Accuracy and Limitations

Static is a Discord bot and depends on Discord, hosting providers, AI providers, and other services to operate.

While reasonable measures are taken to protect stored information, no online service can guarantee absolute security.

Static may experience outages, data loss, corruption, or other technical failures. Users should not rely on Static as a permanent storage service for important information.

10. Children's Privacy

Static is not intended to knowingly collect personal information from children under 13.

Static does not intentionally request information such as names, addresses, passwords, or other sensitive personal information from users.

If you believe Static has collected information from a user under 13, please contact the bot owner or open a support ticket so the information can be reviewed and, where appropriate, deleted.

11. Changes to This Policy

This Privacy Policy may be updated when Static gains new features, changes how information is handled, or otherwise requires changes to its privacy practices.

Significant changes may be announced in the server.

The Last Updated date at the beginning of this policy will be changed whenever the policy is substantially revised.

12. Contact

For questions regarding this Privacy Policy or requests concerning your stored data, contact the Static bot owner or open a support ticket in the designated support server.
